# ptiny.load

Overview

A simple, lightweight server-side downloader inspired by pyLoad.

Source Code

Server(linux)
https://github.com/plustiny/ptinyloadd.git
Client(Android)
https://github.com/plustiny/ptiny.load.git

Installation

Server (Linux)


sudo apt install libmicrohttpd-dev libjansson-dev zlib1g-dev libwrap0-dev

git clone  https://github.com/plustiny/ptinyloadd.git
cd ptinyloadd
vi ptinyloadd.service # config LoadCredential
vi ptinyloadd.conf    # config PORT, NAME, PASSWORD
make
sudo make install
sudo make service

Client (Android)


git clone  https://github.com/plustiny/ptiny.load.git
cd ptiny.load
./gradlew build
adb install app/build/outputs/apk/debug/app-debug.apk

Usage

Send a URL to the app on Android, and it will download it.
